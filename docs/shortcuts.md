# Keyboard shortcuts

Single keys work when no text field has focus. `⌘` is `Ctrl` on Windows and Linux.

| Action                 | Web            | macOS          |
| ---------------------- | -------------- | -------------- |
| Next post              | `j`            | `j`            |
| Previous post          | `k`            | `k`            |
| Mark read and go next  | `e`            | `e`            |
| Toggle read            | `u`            | `u`, `⌘U`      |
| Toggle star            | `s`            | `s`, `⌘D`      |
| Open in browser        | `o`            | `o`, `⇧⌘O`     |
| Write a note           | `n`            | `n`            |
| Search                 | `/`            | `/`            |
| Back to list           | `Esc`          | `Esc`          |
| Keyboard shortcuts     | `?`            | `?`, `⌘/`      |
| Add feed               | `a`            | `a`, `⌘N`      |
| Refresh feeds          | `r`            | `r`, `⌘R`      |
| Full page view         |                | `w`            |
| Command palette        | `⌘K`           | `⌘K`           |
| Toggle sidebar         | `⌘\`           |                |
| Mark all as read       | `⇧⌘K`          | `⇧⌘K`          |
| Unread / All / Starred | `⌘1` `⌘2` `⌘3` | `⌘1` `⌘2` `⌘3` |
| Settings               | `⌘,`           | `⌘,`           |
| Undo last mark         | `z`            | `⌘Z`           |

On the web, `z` reverts the most recent mark-all, read or star change; the toast after a mark-all also offers Undo for six seconds. In All and tag views, mark-all asks for confirmation first.

On macOS the ⌘ variants live in the menu bar (File, Go, Help); the single letters are what tooltips and the shortcuts sheet (`?`) show.
